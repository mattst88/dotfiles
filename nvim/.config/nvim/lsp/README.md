All default language servers should be defined in this file.

You can find the official description of these properties in the documentation,
in [vim.lsp.Config](https://neovim.io/doc/user/lsp.html#vim.lsp.Config). And
the full list of options is in
[vim.lsp.ClientConfig](https://neovim.io/doc/user/lsp.html#vim.lsp.ClientConfig).

The LSPs are themselves managed by Mason
https://mason-registry.dev/registry/list

Good reference can be found with nvim-lspconfig:
https://github.com/neovim/nvim-lspconfig/tree/master/lua/lspconfig/configs
